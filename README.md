# Simple 2D Platformer

Учебный 2D-платформер для Unity 6.5 (URP 2D).

## Запуск

1. Откройте сцену `Assets/Platformer/Scenes/Platformer.unity`.
2. Нажмите Play.

## Управление

- `A` / `D` или стрелки влево / вправо — бег.
- `Space`, `W` или стрелка вверх — прыжок.
- `F` или левая кнопка мыши — атака.

## Реализовано

- физическое движение и прыжок с отдельным чтением ввода;
- Animator Controller с Idle/Run и четырьмя кадрами бега;
- здоровье, получение урона и лечение;
- ближний бой игрока и врагов с анимациями атаки и смерти;
- патрулирование врагов и преследование видимого игрока;
- спавнер из 12 точек, поддерживающий 6 активных монет;
- сбор монет, HUD-счётчик и респавн через 3 секунды;
- случайное размещение и респавн аптечек;
- плавное слежение камеры;
- собственные процедурно созданные пиксельные спрайты.
